# Browser upload options

## Text encoding

Text mode exposes UTF-8 (default), UTF-16 little-endian and UTF-16 big-endian.
The selected encoding applies to typed text and both page/panel clipboard text
uploads. Clipboard files retain their original bytes. Encoding generates no BOM.
Closing options or switching File/Text preserves the selection and text draft;
file mode hides the encoding control. Settings are held in component memory.

Expiry, download limits, key protection and history remain disabled until their
respective implementation is integrated.
