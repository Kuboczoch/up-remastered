## Release blocker

**#134 is not complete. Do not merge this PR yet.** Next.js 16.3.8 overwrites the proxy's `Vary: Accept-Language, Cookie` on rendered HTML/RSC. The final response keeps Next's RSC variation names but loses the application names. Locale-keyed static artifacts, explicit language selection, `Content-Language`, and private/no-store caching work, but do not satisfy the required final Vary contract. `scripts/verify-locale-http.mjs` detects the failure. A proposed pinned dependency patch could not proceed because `pnpm patch next@16.3.8` is awaiting tool security approval. It was not executed, and the restriction was not bypassed.

Parent must arrange the requested actual Astra-profile review after resolving this blocker. Native independent reviews are not a substitute for Astra.

## Actual combined validation

After merging current master and resolving the clipboard race integration, `pnpm run check:full` passed formatting, no-JVM/document/parity guards, lint, typecheck, 434 unit tests, 11 cleanup tests, a fresh production build and **180 Playwright tests: no skips, failures or flakes**. Logs and machine-readable artifacts live outside the repository in the scratch manifest supplied with the PR.

The dedicated stream cancellation test transferred 16,248 actual partial bytes of a 1,048,576-byte file and measured 3% native progress before abort. It observed a retryable request, zero partial files after cancellation, refusal of a parallel upload, and exactly one consumed request after retry. The small 4 KiB test separately identifies its buffered 100% progress/zero-partial evidence and is not represented as an in-flight streaming test.

The general green suite does **not** imply the separate final Vary HTTP acceptance probe is green. Its known failure remains release-blocking.

## Independent reviews

Independent native functional/security review found no new lifecycle or secret-handling implementation blocker; three evidence weaknesses were corrected: hover-sensitive SPA navigation screenshots, an incorrect history storage key, and small-buffer cancellation being mistaken for streaming evidence. Independent architecture review found unknown nested UI paths lacked complete error-document metadata, then found nested request/decrypt soft-404s; both received production browser regression fixes. A neutral merge review preserved master clipboard generation guards and added deferred stale-result tests with genuine negative mutation controls. The known Next Vary defect remains unresolved.
